# 📌 Rules for This Learning Journey

1. Understand before memorizing.
2. Write code yourself before looking at solutions.
3. Always try to debug your own code first.
4. Keep every learning day in Git.
5. Make meaningful commits.
6. Build projects instead of only watching tutorials.
7. Review old knowledge regularly.
8. Ask "why?" instead of only asking "how?".
9. Don't skip fundamentals.
10. Update this README after completing each milestone.
